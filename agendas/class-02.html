Segmentation & Targeting

Connect segmentation analysis to target selection and use the Annie’s case to develop a coherent product and marketing-mix recommendation.

Learning Goals

By the end of class, you should be able to:

  • Evaluate whether a segmentation scheme is managerially useful.
  • Compare target segments using attractiveness, risk, and company fit.
  • Recommend a target using explicit criteria and case evidence.
  • Align product, price, distribution, and promotion with the selected target.
